# Save My Cooldowns

Imagine a game where bug resolutions are so incompetent that [Issue 111801](https://mojira.dev/MC-111801) has not been resolved for a decade already.

Well this mod aims to fix that by saving and loading cooldowns properly, so you don't have to wait for Microslop's Copilot to fix it after GTA 10

## What bug is this in the first place?

If you are holding a shield and a vindicator hits you with an axe, the shield disables. Logging out and back into the world will remove the cooldown, essentially beating the purpose of cooldowns.

## Why would I want this?

Idk girl, this preserves the integrity of items that have longer cooldowns in mods that utilize the vanilla cooldown system. I made this when it was too hot to focus on my main mods, so enjoy ig idk
